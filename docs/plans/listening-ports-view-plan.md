# 열린 포트 한눈에 보기 — 작업 계획

- 상태: 초안 (구현 전)
- 작성일: 2026-10-14
- 브랜치: `feature/listening-ports-view`

## 배경

워크스페이스마다 탭이 여러 개이고, 각 탭에서 dev 서버·프록시·`port-forward` 같은 것을 띄워 두다 보면
"어느 워크스페이스의 어느 탭에서 무엇을 몇 번 포트로 띄웠는지"를 기억해야 한다. 지금 mast에는 이를
한곳에서 보는 화면이 없어서, 탭을 하나씩 열어 보거나 `ss`/`lsof`를 직접 쳐야 한다.

## 목표

한 화면에서 현재 열려 있는(LISTEN) TCP 포트를 아래 정보와 함께 보여 준다.

| 열 | 내용 |
|---|---|
| 포트 | 포트 번호와 바인드 주소(`127.0.0.1`, `0.0.0.0`, `::` 등) |
| 프로세스 | 포트를 연 프로세스의 명령줄 |
| 워크스페이스 / 탭 | 그 프로세스가 속한 mast 워크스페이스와 탭 |

행에서 할 수 있는 동작(우선순위 순):

1. 해당 탭으로 이동
2. 내장 브라우저 탭(ADR-0031)으로 `http://localhost:<port>` 열기
3. URL 복사

## 범위 밖

- 포트를 연 프로세스를 mast에서 종료하는 기능
- UDP 소켓, 외부로 나가는 연결 목록
- mast 탭 밖에서 뜬 프로세스(예: Docker의 `docker-proxy`, systemd 서비스)를 특정 탭에 억지로 귀속하는 것.
  이런 포트는 "mast 탭 밖"으로 묶어서 보여 주거나 숨기는 것 중 하나로 정한다.

## 접근 방향

### 탭 귀속

탭에서 시작한 모든 프로세스는 `MAST_TAB` 환경변수를 상속한다. `mast ls`의 COMMAND 열이 이미 이 값으로
`/proc`에서 탭의 셸과 자손 프로세스를 찾는다(`apps/mast/src-tauri/src/provision.rs`의 `render_tabs`).
같은 방식으로 "LISTEN 소켓을 가진 pid → `MAST_TAB` → 탭 → 워크스페이스"를 이어 붙인다.

### 포트 수집

- **Linux / WSL**: `/proc/net/tcp`, `/proc/net/tcp6`에서 상태 `0A`(LISTEN) 행의 inode를 모으고,
  `/proc/<pid>/fd/*`의 `socket:[inode]` 링크로 pid를 찾는다. 외부 도구에 의존하지 않는다.
- **Windows**: 셸이 WSL 안에서 돌기 때문에 Windows 쪽 Rust가 `/proc`을 직접 읽을 수 없다. 조회 시점에만
  WSL 안에서 수집 스크립트를 한 번 실행한다(`mast ls`의 python과 같은 형태). 다른 distro의 탭은
  `mast ls`와 같은 이유로 보이지 않을 수 있으며, 이 한계는 화면에 표시한다.
- **macOS**: PTY 자식 pid를 알고 있으므로 프로세스 트리로 귀속하고, LISTEN 소켓은 `lsof -nP -iTCP -sTCP:LISTEN`
  또는 `libproc` 중 하나로 수집한다. 둘 중 무엇을 쓸지는 구현 단계에서 정한다.

### 비용 원칙

CLAUDE.md의 제품 원칙(유휴 비용 ≈ 0, 워크스페이스 수에 비례하는 상시 서비스 금지)을 따른다.

- 화면을 열 때와 사용자가 새로고침할 때만 수집한다. 백그라운드 폴링은 하지 않는다.
- 화면을 연 동안의 자동 갱신이 필요하면 짧은 주기·화면 표시 중에만 동작하는 형태로 한정하고, 따로 결정한다.
- 결과는 화면이 들고 있는 일회성 스냅샷이며 모델에 저장하지 않는다.

## 열린 질문

1. **화면 위치**: 새 뷰어 탭 종류(ADR-0008의 viewer 탭 계열)로 둘지, 사이드바 패널·오버레이로 둘지.
2. **범위**: 현재 워크스페이스만 볼지, 전체 워크스페이스를 한 번에 볼지(요청 의도는 전체).
3. **mast 탭 밖 포트**: 숨길지, 별도 그룹으로 보여 줄지.
4. **CLI**: `mast ports` 같은 CLI 명령을 함께 둘지(에이전트가 자기 dev 서버 포트를 찾는 용도).

## 검증 계획(초안)

- 포트 파싱·탭 귀속 로직은 `mast-core`에서 고정된 `/proc` 픽스처로 단위 테스트한다.
- 실제 LISTEN 소켓을 열고 수집하는 통합 테스트는 Linux 전용으로 둔다.
- 저장소 게이트(CLAUDE.md "Gates")를 통과한 뒤, Windows(WSL)와 macOS에서 수동 확인 체크리스트를 돌린다.
