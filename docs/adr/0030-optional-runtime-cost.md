# ADR-0030: 사용하지 않는 기능의 초기화 비용 제거

- 상태: 채택
- 날짜: 2026-09-20

자동 UI 리셋을 모두 꺼도 supervisor 스레드와 프런트 활동 보고가 남았고,
뷰어를 열기 전에도 모든 뷰어 코드와 Markdown 파서가 초기화되었다.

세 리셋 트리거가 모두 꺼지면 supervisor의 정책·공유 상태·스레드를 생성하지 않는다.
백엔드의 실제 활성 상태를 부팅 때 조회해 프런트 활동 리스너도 생략한다.
수동 리셋과 에이전트 알림·Windows 토스트는 별도 경로로 유지한다.
기존 환경 변수와 기본값을 유지하며 새 설정 키는 추가하지 않는다.

폴더·텍스트·Markdown·Git 변경·종료 기록 뷰어는 처음 표시할 때 모듈을 로딩한다.
모듈은 이후 재사용하지만 뷰 인스턴스는 기존처럼 표시 중인 탭에만 유지한다.
로딩 중 탭이 닫히면 생성자를 호출하지 않고, 변경된 경로는 최신 값으로 생성자에
전달한다. 로딩 화면이 포커스를 유지한 경우에만 완성된 뷰어로 포커스를 넘긴다.
로딩 실패는 화면에 표시한다.

검증은 리셋 트리거 조합, 활동 리스너의 비활성화, 비동기 뷰어의 닫기·갱신·포커스·실패
경로를 대상으로 한다. 프로덕션 번들의 정적 import 그래프에서 뷰어와 Markdown 파서가
제외되는지도 확인한다. 번들 크기 감소를 실제 RAM 감소량으로 해석하지 않는다.
